# Screener Analyst

Upload a Chartink screener screenshot and receive a structured swing-trading analysis for Indian stocks.

## Stack

- Next.js 16 and React 19
- Vercel AI Gateway with Claude vision
- Tailwind CSS

## Run locally

```bash
pnpm install
pnpm dev
```

Set `AI_GATEWAY_API_KEY` in `.env.local` before submitting an analysis.

## Deploy

Deploy to Vercel and configure `AI_GATEWAY_API_KEY` as an environment variable. See `DEPLOYMENT.md` for details.
